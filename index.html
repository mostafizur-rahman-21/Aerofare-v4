AeroFare — Viva Guide & Architecture

Computer Science & Engineering 1st Semester Project • Team K

Project Problem Statement & Goal

Domestic flight ticket prices in India fluctuate dynamically based on demand, lead time, and route factors. Passengers frequently overpay because they lack historical fare transparency. AeroFare estimates fair historical ticket prices using Machine Learning (Random Forest Regressor) and compares them with real-time live quotes (Google Flights) to alert users about price surges and propose smart backup alternatives.

Machine Learning Engine (Random Forest Regressor)

Algorithm Used: Random Forest Regressor (scikit-learn)
Holdout Test Accuracy: Mean Absolute Error (MAE): ~₹1,084.95
Training Dataset: Kaggle Indian Domestic Flights (300,000+ rows)
Features (29 Encodings): Days Left, Duration, Stops, Airline, Class, City, Timing

3-Tier Smart Backup Engine (Core Novelty)

When flights are unavailable on a chosen date or when live prices surge significantly above the ML baseline, AeroFare automatically recommends 3 backup alternatives:

  • Flexible Travel Dates: Evaluates 5 nearby days (±3 days) using ML to find dates with lower demand and cheaper fares.
  • Alternative Carriers: Identifies other domestic airlines flying the same sector with lower fares.
  • Indian Railways Express Backup: Provides confirmed high-speed express trains (e.g. Vande Bharat / Rajdhani Express) with fixed AC tariffs and zero surge pricing.

Common Viva Questions & Model Answers

Q1: Why did you choose Random Forest over Linear Regression?

Linear regression assumes linear relationships, whereas flight pricing is non-linear (e.g. exponential price increases in the last 3 days). Random Forest captures these non-linearities and interactions between features without overfitting.

Q2: What is the purpose of the 45-day booking window trend chart?

It allows users to visually identify the optimal advance booking window for their specific route. Historically, booking 14–21 days in advance yields the lowest domestic fares.

Q3: How does the app handle when the live API fails or runs out of quota?

The application has graceful fault tolerance: it falls back to the historical ML prediction and built-in simulation mode, ensuring the user interface remains fully functional.
